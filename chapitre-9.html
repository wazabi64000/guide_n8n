Module 9

n8n + Intelligence Artificielle

Combinez la puissance de l'IA générative avec n8n pour créer des chatbots, analyser du texte et automatiser des tâches intelligentes.

Modèles IA disponibles dans n8n

🤖 OpenAI

GPT-4, GPT-3.5. Nœud natif. Idéal pour chatbots et génération de texte.

🧠 Claude (Anthropic)

Via HTTP Request ou nœud AI Agent. Excellent pour l'analyse longue.

🇫🇷 Mistral

Modèle français. API compatible OpenAI. Bon rapport qualité/prix.

✨ Gemini (Google)

Multimodal. Analyse texte + images. Nœud Google AI.

Projet 1 : Chatbot FAQ

Question utilisateur
→
n8n Webhook
→
OpenAI GPT
→
Réponse JSON
// Nœud OpenAI — Chat
Model: gpt-4o-mini
System Prompt: Tu es un assistant FAQ pour notre entreprise.
  Voici notre documentation : [coller FAQ ici]
  Réponds uniquement en te basant sur cette documentation.
  Si tu ne sais pas, dis "Je ne peux pas répondre à cette question."

User Message: {{ $json.body.question }}

Projet 2 : Analyse de sentiment

// Nœud OpenAI
System Prompt: Analyse le sentiment du texte suivant.
  Réponds UNIQUEMENT en JSON : {"sentiment": "positif|negatif|neutre", "score": 0-100, "resume": "..."}

User Message: {{ $json.text }}

Projet 3 : Résumé automatique

// Nœud OpenAI
System Prompt: Résume le texte suivant en 3 points clés maximum.
  Sois concis et factuel.

User Message: {{ $json.article }}

Projet 4 : Classification automatique

// Nœud OpenAI
System Prompt: Classifie cet email dans UNE catégorie :
  - support technique
  - facturation
  - commercial
  - spam
  Réponds en JSON : {"category": "...", "confidence": 0-100}

User Message: Objet: {{ $json.subject }}
  Corps: {{ $json.body }}

Utiliser Mistral (API compatible OpenAI)

// Nœud HTTP Request (compatible OpenAI)
POST https://api.mistral.ai/v1/chat/completions
Headers:
  Authorization: Bearer {{ $credentials.mistralApiKey }}
  Content-Type: application/json
Body: {
  "model": "mistral-small-latest",
  "messages": [
    {"role": "system", "content": "Tu es un assistant utile."},
    {"role": "user", "content": "{{ $json.question }}"}
  ]
}

Exercices pratiques

📝 Exercice 1 — Chatbot FAQ simple
  1. Créez : Webhook → OpenAI → Respond to Webhook
  2. Configurez un system prompt avec 5 questions/réponses de votre choix
  3. Testez avec : curl -X POST .../webhook/faq -d '{"question":"Quels sont vos horaires ?"}'
📝 Exercice 2 — Classifier des emails
  1. Webhook reçoit {"subject":"...", "body":"..."}
  2. OpenAI classifie l'email
  3. IF category = "support" → créer ticket (HTTP Request simulé)
  4. IF category = "spam" → ignorer
  5. Sinon → notifier l'équipe commerciale

Après OpenAI, ajoutez un nœud Code pour parser le JSON :

const response = JSON.parse($json.message.content);
return [{ json: { ...response, original: $('Webhook').item.json.body } }];

Puis un nœud Switch sur {{ $json.category }} avec 4 branches.

💡 Bonnes pratiques IA
  • Toujours demander une réponse JSON structurée pour faciliter le parsing
  • Limiter le contexte (tokens) pour réduire les coûts
  • Utiliser gpt-4o-mini pour les tâches simples (moins cher)
  • Tester les prompts avant de déployer en production
  • Prévoir un fallback si l'IA ne répond pas correctement

📋 Résumé

  • n8n intègre OpenAI, Mistral, Gemini nativement ou via HTTP
  • System prompt = clé du comportement IA
  • Cas d'usage : FAQ, sentiment, résumé, classification
  • Combiner IA + IF/Switch pour des workflows intelligents
