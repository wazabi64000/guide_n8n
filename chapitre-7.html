Module 7

Automatisation E-commerce

Automatisez le traitement des commandes : notification, facturation et suivi — de Shopify, WooCommerce ou Stripe vers vos outils.

Nouvelle commande
→
n8n
→
Email confirmation
→
Facture PDF

Plateformes supportées

🛍️ Shopify

Nœud natif n8n. Trigger « Order Created ». Accès complet aux données commande, client, produits.

🛒 WooCommerce

Via webhook ou nœud WooCommerce. Idéal pour les sites WordPress.

💳 Stripe

Trigger « Payment Succeeded ». Parfait pour les paiements directs.

Projet guidé : Commande Shopify → Email + Facture

Étape 1 — Trigger Shopify

// Nœud Shopify Trigger
Event: Order Created
Credentials: Shopify API (clé + secret)

Étape 2 — Extraire les données

// Nœud Set
orderId    → {{ $json.id }}
customer   → {{ $json.customer.first_name }} {{ $json.customer.last_name }}
email      → {{ $json.customer.email }}
total      → {{ $json.total_price }}
currency   → {{ $json.currency }}
items      → {{ $json.line_items.map(i => i.title).join(", ") }}
orderDate  → {{ $json.created_at }}

Étape 3 — Email de confirmation

// Nœud Gmail ou Brevo
To: {{ $json.email }}
Subject: Confirmation commande #{{ $json.orderId }}
Body: Bonjour {{ $json.customer }},
      Merci pour votre commande de {{ $json.total }}{{ $json.currency }}.
      Articles : {{ $json.items }}

Étape 4 — Générer la facture

// Nœud HTTP Request vers un service PDF
// Ou Google Docs template + PDF conversion
Method: POST
URL: https://api.pdfmonkey.io/api/v1/documents
Body: {
  "document": {
    "order_id": "{{ $json.orderId }}",
    "customer": "{{ $json.customer }}",
    "total": "{{ $json.total }}",
    "items": "{{ $json.items }}"
  }
}

Intégration Stripe

// Nœud Stripe Trigger
Event: payment_intent.succeeded

// Données disponibles :
amount     → {{ $json.amount / 100 }}  // Stripe utilise les centimes
email      → {{ $json.receipt_email }}
currency   → {{ $json.currency }}

Exercice pratique

📝 Exercice — Workflow commande simulée
  1. Créez un workflow : Webhook → Set → IF (total > 50) → Email → Slack
  2. Simulez une commande : 
    curl -X POST http://localhost:5678/webhook/order \
  -H "Content-Type: application/json" \
  -d '{
    "id": "ORD-001",
    "customer": {"first_name":"Paul","last_name":"Martin","email":"paul@test.com"},
    "total_price": "75.00",
    "currency": "EUR",
    "line_items": [{"title":"T-shirt"},{"title":"Casquette"}]
  }'
  3. Si total > 50€ : envoyer notification « Grosse commande ! » sur Slack
  4. Sinon : notification standard
  5. Logger la commande dans Google Sheets (HTTP Request ou nœud natif)

IF Node : {{ parseFloat($json.total) > 50 }}

True : Slack → 🎉 Grosse commande ! {{ $json.customer }} — {{ $json.total }}€

False : Slack → 📦 Nouvelle commande {{ $json.orderId }} — {{ $json.total }}€
