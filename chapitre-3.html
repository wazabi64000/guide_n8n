Bienvenue dans n8n

Créez votre premier workflow ou explorez les templates.

Dashboard (Overview)

Page d'accueil après connexion. Affiche :

  • Statistiques des exécutions récentes (succès/échecs)
  • Accès rapide pour créer un workflow
  • Liens vers la documentation et la communauté

Workflows

Le cœur de n8n. C'est ici que vous créez, modifiez et gérez vos automatisations.

Actions clés : Nouveau workflow (+), Activer/Désactiver (toggle), Exécuter (▶), Sauvegarder (Ctrl+S)

Executions

Historique de toutes les exécutions de vos workflows. Pour chaque exécution :

  • Statut (succès ✅, échec ❌, en cours ⏳)
  • Date et durée
  • Données entrantes/sortantes de chaque nœud
  • Possibilité de relancer (retry)
💡 Astuce debug

Cliquez sur une exécution échouée pour voir exactement quel nœud a planté et les données à ce moment-là.

Credentials

Stockage sécurisé de vos identifiants API. Types courants :

API Key

Clé simple (ex: VirusTotal, OpenAI)

OAuth2

Connexion Google, Slack, etc.

Basic Auth

Login + mot de passe HTTP

Les credentials sont chiffrés et réutilisables dans tous vos workflows.

Templates

Bibliothèque de workflows pré-construits par la communauté. Parcourez par catégorie (Marketing, IT Ops, Sales…) et importez en un clic pour partir d'une base solide.

Exercice pratique

📝 Exercice — Créer son premier workflow
  1. Connectez-vous à n8n (localhost:5678)
  2. Cliquez sur Workflows puis + Add workflow
  3. Cliquez sur + pour ajouter un nœud → cherchez « Manual Trigger »
  4. Ajoutez un nœud Set et connectez-le au trigger
  5. Dans Set, ajoutez un champ : message = Bonjour n8n !
  6. Cliquez Execute Workflow (▶)
  7. Vérifiez le résultat dans le panneau de droite
  8. Sauvegardez avec Ctrl+S et nommez le workflow
