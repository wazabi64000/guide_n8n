Module 1

Introduction à n8n

Découvrez l'outil d'automatisation open-source qui permet de connecter vos applications sans écrire des centaines de lignes de code.

Qu'est-ce que n8n ?

n8n (prononcé « n-eight-n ») est une plateforme d'automatisation de workflows open-source. Elle permet de relier des applications entre elles (Gmail, Slack, Shopify, bases de données…) via une interface visuelle de type « glisser-déposer ».

Concrètement, n8n remplace les tâches répétitives : envoyer un email quand un formulaire est soumis, synchroniser un CRM avec une feuille de calcul, analyser une URL avec VirusTotal… Le tout sans développer une application complète.

Pourquoi n8n existe ?

Les développeurs et les équipes métier perdent un temps considérable sur des tâches manuelles : copier des données d'un outil à l'autre, déclencher des actions à la main, surveiller des événements. n8n a été créé pour :

  • Automatiser ces flux de travail sans tout recoder
  • Centraliser les intégrations dans un seul outil
  • Donner le contrôle : code open-source, auto-hébergement possible
  • Permettre le low-code ET le code : expressions JavaScript quand nécessaire

Cas d'utilisation réels

Un prospect remplit un formulaire Facebook → n8n récupère les données → les envoie dans HubSpot → déclenche un email de bienvenue via Brevo.
Shopify notifie n8n d'une commande → génération de facture PDF → envoi par email → mise à jour du stock dans Google Sheets.
Un analyste soumet une URL suspecte → n8n interroge VirusTotal → compile un rapport → l'envoie sur Slack.
Nouvel employé dans le SIRH → création compte Google Workspace → ajout Slack → envoi du kit de bienvenue.

Concepts fondamentaux

Workflow

Ensemble de nœuds connectés formant une automatisation complète. C'est votre « programme » visuel.

Node (Nœud)

Brique élémentaire : un trigger, une action ou une transformation. Chaque nœud fait une chose précise.

Trigger

Point de départ : webhook, cron (planification), événement d'une app. Déclenche le workflow.

Action

Opération exécutée : envoyer un email, créer un enregistrement, appeler une API.

Credentials

Identifiants sécurisés (clés API, OAuth) stockés de manière chiffrée dans n8n.

Webhook

URL unique qui reçoit des données HTTP (POST/GET) et démarre un workflow.

Exécution

Chaque lancement d'un workflow. Consultable dans l'onglet Executions avec logs détaillés.

Exercice pratique

📝 Exercice — Créer un workflow simple

Objectif : Comprendre la logique d'un workflow avant de l'installer.

  1. Sur papier ou dans un éditeur, dessinez un workflow avec ces étapes : Formulaire contact → Vérification email → Envoi notification Slack
  2. Identifiez le trigger, les transformations et les actions
  3. Listez les credentials nécessaires
  4. Prévoyez ce qui se passe si l'email est invalide (branche alternative)

  • Zapier est open-source
  • n8n peut être auto-hébergé gratuitement
  • n8n n'a pas de nœuds
  • Zapier utilise JavaScript

Bonnes pratiques

💡 Conseils pour débuter
  • Commencez par des workflows simples (2-3 nœuds) avant les projets complexes
  • Nommez clairement vos workflows et nœuds
  • Testez chaque nœud individuellement avec « Execute Node »
  • Documentez vos workflows avec des notes (Sticky Notes dans n8n)
