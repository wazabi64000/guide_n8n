Module 6

Automatisation Marketing

Automatisez la capture et le traitement de vos leads marketing : de Facebook Lead Ads jusqu'à l'email de bienvenue.

Facebook Lead Ads
→
n8n Webhook
→
CRM (HubSpot)
→
Email Brevo

Pourquoi automatiser le marketing ?

Chaque minute compte quand un prospect montre de l'intérêt. L'automatisation permet de :

  • Capturer les leads instantanément (24h/24)
  • Éliminer la saisie manuelle (erreurs, oublis)
  • Déclencher des emails personnalisés en quelques secondes
  • Centraliser les contacts dans un CRM

Projet : Facebook Lead Ads → n8n → Brevo

Étape 1 — Configurer le Webhook dans n8n

  1. Créez un workflow avec un nœud Webhook (POST)
  2. Activez le workflow et copiez l'URL du webhook
  3. Dans Facebook Lead Ads, configurez l'intégration webhook avec cette URL

Étape 2 — Transformer les données du lead

// Nœud Set — Mapper les champs Facebook
firstName  → {{ $json.body.field_data[0].values[0] }}
email      → {{ $json.body.field_data[1].values[0] }}
phone      → {{ $json.body.field_data[2].values[0] }}
source     → "facebook-lead-ads"
capturedAt → {{ $now.toISO() }}

Étape 3 — Ajouter au CRM

Utilisez le nœud HubSpot (ou HTTP Request vers votre CRM) :

Operation: Create Contact
Email: {{ $json.email }}
First Name: {{ $json.firstName }}
Phone: {{ $json.phone }}
Lead Source: {{ $json.source }}

Étape 4 — Email de bienvenue via Brevo

// Nœud Brevo (Sendinblue)
To: {{ $json.email }}
Template ID: 1
Params: {
  "PRENOM": "{{ $json.firstName }}"
}

Exercice pratique

📝 Exercice — Simuler un lead Facebook
  1. Créez le workflow Webhook → Set → Brevo (ou HTTP Request simulant un email)
  2. Simulez un lead avec curl : 
    curl -X POST http://localhost:5678/webhook/lead \
  -H "Content-Type: application/json" \
  -d '{
    "field_data": [
      {"name":"first_name","values":["Marie"]},
      {"name":"email","values":["marie@example.com"]},
      {"name":"phone","values":["0612345678"]}
    ]
  }'
  3. Vérifiez que les données sont correctement mappées dans le nœud Set
  4. Ajoutez un nœud IF pour filtrer les emails invalides
  5. Ajoutez une notification Slack en cas de nouveau lead

Nœud IF : Condition {{ $json.email }} matches regex ^[^\s@]+@[^\s@]+\.[^\s@]+$

Branche true : HubSpot → Brevo → Slack

Branche false : Log l'erreur ou notification admin

Slack message : Nouveau lead : {{ $json.firstName }} ({{ $json.email }}) via {{ $json.source }}
