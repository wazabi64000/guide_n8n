Module 2

Installation de n8n

Plusieurs méthodes existent pour installer n8n. Nous allons les explorer une par une, avec chaque commande expliquée ligne par ligne.

Prérequis

  • Node.js version 18 ou supérieure (pour npm/npx)
  • Docker (optionnel, recommandé en production)
  • Un serveur Linux ou VPS pour la production

Méthode 1 — npx (test rapide)

La façon la plus rapide de tester n8n sans installation permanente.

# Lance n8n sans l'installer globalement
npx n8n

# npx      → exécute un package npm sans installation globale
# n8n      → nom du package à exécuter
# Résultat → serveur sur http://localhost:5678
💡 Pourquoi npx ?

Idéal pour un premier test. Les données sont stockées dans ~/.n8n. Pas recommandé en production.

Méthode 2 — npm (installation globale)

# Installe n8n globalement sur votre machine
npm install n8n -g

# npm install → commande d'installation de packages Node.js
# n8n        → package à installer
# -g         → global : accessible depuis n'importe quel terminal

# Puis lancez le serveur :
n8n start

# n8n start  → démarre le serveur n8n sur le port 5678

Méthode 3 — Docker (recommandée)

# Lancement simple avec Docker
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

# docker run    → crée et démarre un conteneur
# -it           → mode interactif avec terminal
# --rm          → supprime le conteneur à l'arrêt
# --name n8n    → nomme le conteneur "n8n"
# -p 5678:5678  → mappe le port 5678 (hôte:conteneur)
# -v ~/.n8n:... → volume persistant pour les données
# n8nio/n8n     → image Docker officielle

Docker Compose (production)

Créez un fichier docker-compose.yml :

version: '3.8'
services:
  n8n:
    image: n8nio/n8n
    restart: always
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=motdepasse
      - N8N_HOST=n8n.mondomaine.com
      - WEBHOOK_URL=https://n8n.mondomaine.com/
    volumes:
      - n8n_data:/home/node/.n8n

volumes:
  n8n_data:
# Démarre les services en arrière-plan
docker compose up -d

# docker compose → outil de gestion multi-conteneurs
# up            → crée et démarre les conteneurs
# -d            → detached : en arrière-plan

Méthode 4 — systemd (serveur Linux)

Pour un service permanent sur un VPS Linux :

# /etc/systemd/system/n8n.service
[Unit]
Description=n8n workflow automation
After=network.target

[Service]
Type=simple
User=node
ExecStart=/usr/bin/n8n start
Restart=on-failure
Environment=N8N_PORT=5678

[Install]
WantedBy=multi-user.target
# Recharge la configuration systemd
sudo systemctl daemon-reload

# Active n8n au démarrage du serveur
sudo systemctl enable n8n

# Démarre le service maintenant
sudo systemctl start n8n

# Vérifie le statut
sudo systemctl status n8n

Méthode 5 — PM2 (process manager Node.js)

# Installe PM2 globalement
npm install pm2 -g

# Démarre n8n avec PM2
pm2 start n8n --name "n8n"

# pm2 start → lance un processus géré par PM2
# --name     → nom lisible pour le processus

# Sauvegarde la config pour redémarrage auto
pm2 save
pm2 startup

n8n Cloud

Si vous ne voulez pas gérer l'infrastructure, n8n Cloud (https://n8n.io) héberge tout pour vous. Compte gratuit limité, puis abonnement. Idéal pour débuter sans serveur.

Exercice pratique

📝 Exercice — Installer n8n en local
  1. Vérifiez Node.js : node --version (doit être ≥ 18)
  2. Lancez n8n avec npx n8n
  3. Ouvrez http://localhost:5678 dans votre navigateur
  4. Créez votre compte administrateur
  5. Arrêtez le serveur avec Ctrl+C
  6. (Bonus) Relancez avec Docker si installé
node --version    # v20.x.x → OK
npx n8n           # Démarre le serveur
# Navigateur → http://localhost:5678
# Créer compte → email + mot de passe
# Ctrl+C pour arrêter

Si le port 5678 est occupé : N8N_PORT=5679 npx n8n

💡 Bonnes pratiques
  • Toujours utiliser des volumes Docker pour persister les données
  • Activer l'authentification en production (N8N_BASIC_AUTH)
  • Configurer WEBHOOK_URL pour que les webhooks fonctionnent
  • Utiliser HTTPS avec un reverse proxy (Nginx/Caddy)

📋 Résumé

  • npx pour tester, Docker pour la production
  • Le port par défaut est 5678
  • Les données sont dans ~/.n8n ou un volume Docker
  • PM2 et systemd pour la gestion de processus
