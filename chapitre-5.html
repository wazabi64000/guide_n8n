Module 5

Manipulation des données

Les données circulent entre les nœuds sous forme de JSON. Maîtriser les expressions est essentiel pour créer des workflows puissants.

Le format JSON dans n8n

Chaque nœud reçoit et produit des items. Un item contient un objet JSON :

{
  "json": {
    "name": "Alice",
    "email": "alice@example.com",
    "age": 28
  }
}

Les données du nœud précédent sont accessibles via $json dans les expressions.

Les expressions n8n

Syntaxe : {{ expression }} — évaluée au moment de l'exécution.

ExpressionDescriptionExemple de résultat
{{ $json.name }}Champ du nœud courantAlice
{{ $json.email }}Email du contactalice@example.com
{{ $now }}Date/heure actuelle2026-06-22T14:30:00
{{ $now.toISO() }}Date format ISO2026-06-22T14:30:00.000Z
{{ $('Webhook').item.json.body }}Données d'un nœud spécifiqueobjet body
{{ $json.name.toUpperCase() }}Méthode JavaScriptALICE
{{ $json.price * 1.2 }}Calcul mathématique120

Variables utiles

$json

Données JSON de l'item courant

$input

Tous les items en entrée du nœud

$now

Date/heure actuelle (objet Luxon)

$env

Variables d'environnement

$workflow

Infos sur le workflow (id, name)

$execution

Infos sur l'exécution en cours

Transformations courantes

// Concaténer du texte
{{ "Bonjour " + $json.name + " !" }}

// Condition ternaire
{{ $json.age >= 18 ? "Majeur" : "Mineur" }}

// Formatter une date
{{ $now.toFormat('dd/MM/yyyy HH:mm') }}

// Accéder à un tableau
{{ $json.tags[0] }}

// Longueur d'une chaîne
{{ $json.description.length }}

Exercice pratique

📝 Exercice — Transformer des données client

À partir de ce JSON reçu par webhook :

{"firstName":"Jean","lastName":"Dupont","email":"jean.dupont@mail.com","orderTotal":89.99}

Utilisez un nœud Set pour créer ces champs :

  1. fullName → prénom + espace + nom
  2. emailDomain → partie après le @ de l'email
  3. totalTTC → orderTotal × 1.20 (TVA 20%)
  4. processedAt → date actuelle au format ISO
  5. orderLabel → "Commande de [fullName] : [totalTTC]€"
fullName     → {{ $json.firstName + " " + $json.lastName }}
emailDomain  → {{ $json.email.split("@")[1] }}
totalTTC     → {{ ($json.orderTotal * 1.2).toFixed(2) }}
processedAt  → {{ $now.toISO() }}
orderLabel   → {{ "Commande de " + $json.firstName + " " + $json.lastName + " : " + ($json.orderTotal * 1.2).toFixed(2) + "€" }}

Résultat attendu :

{
  "fullName": "Jean Dupont",
  "emailDomain": "mail.com",
  "totalTTC": "107.99",
  "processedAt": "2026-06-22T14:30:00.000Z",
  "orderLabel": "Commande de Jean Dupont : 107.99€"
}

💡 Bonnes pratiques
  • Utilisez l'éditeur d'expressions (icône ⚡) pour tester en direct
  • Préférez Set pour les transformations simples, Code pour la logique complexe
  • Vérifiez les types : un nombre en string ne calcule pas correctement
  • Utilisez .toFixed(2) pour les montants monétaires

📋 Résumé

  • Les données circulent en JSON entre les nœuds
  • Expressions {{ }} pour accéder et transformer les données
  • $json, $now, $input sont les variables les plus utilisées
  • JavaScript est disponible dans les expressions et le nœud Code
