Architecture du projet

L'utilisateur soumet une URL via un formulaire web. n8n lance 5 analyses en parallèle, puis compile un rapport final.

🦠 VirusTotal

Analyse de réputation de l'URL (malware, phishing)

🔍 OWASP ZAP

Scan de vulnérabilités web (XSS, SQLi, etc.)

💡 Lighthouse

Performance, accessibilité, SEO, bonnes pratiques

🛡️ Mozilla Observatory

Score de sécurité HTTP (headers, TLS, CSP)

🔒 Security Headers

Analyse des en-têtes de sécurité HTTP

Workflow principal

Étape 1 — Réception de l'URL

// Webhook POST /audit
Input: { "url": "https://example.com" }

// Set — Normaliser l'URL
targetUrl  → {{ $json.body.url }}
auditId    → {{ $now.toMillis() }}
startedAt  → {{ $now.toISO() }}

Étape 2 — Analyses en parallèle

Utilisez un nœud qui split les branches (le webhook alimente 5 branches simultanées) :

POST https://www.virustotal.com/api/v3/urls
Body: url={{ $json.targetUrl }}
→ Extraire: malicious, suspicious, harmless counts
→ Score: {{ malicious / (malicious + harmless) * 100 }}
GET https://securityheaders.com/?q={{ $json.targetUrl }}&followRedirects=on
→ Parser le grade (A+, A, B, C, F)
→ Lister les headers manquants
POST https://observatory-api.mdn.mozilla.net/api/v2/scan?host={{ domain }}
→ Récupérer le score (0-100)
→ Lister les tests échoués
GET https://www.googleapis.com/pagespeedonline/v5/runPagespeed
  ?url={{ $json.targetUrl }}&category=PERFORMANCE&category=SEO
→ Scores: performance, accessibility, best-practices, seo
POST ZAP API → scan URL
→ Wait 120s
→ GET alerts (High, Medium, Low)
→ Compter par sévérité

Étape 3 — Merge et rapport final

// Nœud Merge — Combiner les 5 branches
// Nœud Code — Générer le rapport
const report = {
  auditId: $('Set').item.json.auditId,
  url: $('Set').item.json.targetUrl,
  date: new Date().toISOString(),
  scores: {
    virusTotal: items[0].json.vtScore,
    securityHeaders: items[1].json.grade,
    observatory: items[2].json.obsScore,
    lighthouse: items[3].json.performance,
    zap: items[4].json.alertCount
  },
  globalScore: calculateGlobal(items),
  recommendations: generateRecommendations(items)
};
return [{ json: report }];

Étape 4 — Livraison du rapport

// Options de livraison :
1. Respond to Webhook → JSON au client
2. Email → Rapport HTML formaté
3. Slack → Résumé avec score global
4. Google Docs → Rapport PDF archivé

Interface utilisateur (formulaire HTML)

Créez une page HTML simple qui appelle votre webhook :

<form id="auditForm">
  <input type="url" id="url" placeholder="https://example.com" required>
  <button type="submit">Lancer l'audit</button>
</form>
<div id="result"></div>

<script>
document.getElementById('auditForm').addEventListener('submit', async (e) => {
  e.preventDefault();
  const url = document.getElementById('url').value;
  const res = await fetch('http://localhost:5678/webhook/audit', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ url })
  });
  const report = await res.json();
  document.getElementById('result').innerHTML =
    `<h3>Score global : ${report.globalScore}/100</h3>
     <pre>${JSON.stringify(report, null, 2)}</pre>`;
});
</script>

Exercice — Construire le projet

📝 Projet Final — Étapes
  1. Créez le workflow webhook avec normalisation URL
  2. Implémentez au minimum 2 branches d'analyse (VirusTotal + Security Headers)
  3. Mergez les résultats dans un rapport JSON
  4. Calculez un score global (moyenne pondérée)
  5. Renvoyez le rapport via Respond to Webhook
  6. Créez le formulaire HTML et testez end-to-end
  7. (Bonus) Ajoutez OpenAI pour générer des recommandations en langage naturel
  8. (Bonus) Envoyez le rapport par email
