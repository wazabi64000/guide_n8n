Module 8

Automatisation Cybersécurité

Découvrez comment automatiser des contrôles de sécurité avec n8n : analyse d'URL, scan de domaines et vérification d'adresses IP.

Pourquoi automatiser la cybersécurité ?

Les analystes sécurité passent beaucoup de temps sur des vérifications répétitives. n8n permet d'automatiser :

  • L'analyse d'URLs suspectes (phishing, malware)
  • Le scan de vulnérabilités web
  • La vérification de réputation IP
  • La génération de rapports consolidés

Projet 1 : Analyse d'URL avec VirusTotal

URL soumise
→
n8n
→
VirusTotal API
→
Rapport
// Nœud HTTP Request — VirusTotal
Method: POST
URL: https://www.virustotal.com/api/v3/urls
Headers:
  x-apikey: {{ $credentials.virusTotalApi }}
Body (form-urlencoded):
  url: {{ $json.url }}

// Puis GET pour récupérer le rapport :
URL: https://www.virustotal.com/api/v3/analyses/{{ $json.data.id }}

Projet 2 : Scan de domaine avec OWASP ZAP

Domaine
→
n8n
→
OWASP ZAP API
→
Rapport PDF
// 1. Lancer le scan ZAP
POST http://zap-server:8080/JSON/ascan/action/scan/
  ?url={{ $json.domain }}&recurse=true

// 2. Attendre (nœud Wait — 60 secondes)

// 3. Récupérer les alertes
GET http://zap-server:8080/JSON/core/view/alerts/
  ?baseurl={{ $json.domain }}

// 4. Générer le rapport HTML/PDF
GET http://zap-server:8080/OTHER/core/other/htmlreport/

Projet 3 : Score IP avec AbuseIPDB

Adresse IP
→
n8n
→
AbuseIPDB
→
Score
// Nœud HTTP Request — AbuseIPDB
GET https://api.abuseipdb.com/api/v2/check
Headers:
  Key: {{ $credentials.abuseIpDbKey }}
  Accept: application/json
Query:
  ipAddress: {{ $json.ip }}
  maxAgeInDays: 90

// Résultat :
abuseScore → {{ $json.data.abuseConfidenceScore }}  // 0-100
country    → {{ $json.data.countryCode }}
isp        → {{ $json.data.isp }}

Exercices pratiques

📝 Exercice 1 — Scanner une URL
  1. Créez un workflow : Webhook → VirusTotal → Set (formater) → Respond
  2. Le webhook reçoit {"url": "https://example.com"}
  3. Formatez la réponse : score, nombre de détections, verdict
  4. Renvoyez un JSON avec safe: true/false (safe si détections < 3)
📝 Exercice 2 — Vérifier une IP
  1. Workflow : Webhook → AbuseIPDB → IF (score > 50) → Slack alerte
  2. Si score > 50 : envoyer alerte « IP suspecte » sur Slack
  3. Sinon : logger « IP propre » dans un fichier/réponse
// Nœud Set — Formater résultat VirusTotal
url         → {{ $('Webhook').item.json.body.url }}
detections  → {{ $json.data.attributes.last_analysis_stats.malicious }}
total       → {{ $json.data.attributes.last_analysis_stats }}
safe        → {{ $json.data.attributes.last_analysis_stats.malicious < 3 }}
verdict     → {{ $json.data.attributes.last_analysis_stats.malicious < 3 ? "SAFE" : "DANGER" }}

IF : {{ $json.data.abuseConfidenceScore > 50 }}

True : Slack → 🚨 IP suspecte : {{ $json.ip }} — Score: {{ $json.data.abuseConfidenceScore }}%

False : Respond → {"status": "clean", "ip": "...", "score": 0}

Que mesure AbuseIPDB ?

⚠️ Sécurité
  • Ne jamais exposer vos clés API dans les workflows (utilisez Credentials)
  • Limiter l'accès aux webhooks de sécurité (authentification)
  • Respecter les limites de taux (rate limits) des APIs
  • Ne scannez que des ressources dont vous êtes propriétaire

📋 Résumé

  • VirusTotal pour analyser les URLs et fichiers
  • OWASP ZAP pour scanner les vulnérabilités web
  • AbuseIPDB pour vérifier la réputation des IP
  • n8n orchestre ces outils et génère des rapports unifiés
